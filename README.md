# AI × Web3 School Learning Repository

欢迎来到我的 **AI × Web3 School** 个人学习仓库！

这个仓库用于记录我在 AI × Web3 School 期间的：
- 学习日志（Learning Log）
- 任务证明（Proof of Work）
- 实验记录（Experiment Records）
- 每日打卡草稿（Daily Check-in Drafts）
- Handbook 反馈（Handbook Feedback）
- Hackathon 准备与提交（Hackathon Prep & Submissions）

## 官方入口
- AI × Web3 School Handbook: https://aiweb3.school/zh/handbook/
- WCB 课程页面: https://web3career.build/zh/programs/AI-Web3-School
- WCB Learning 页面: https://web3career.build/zh/programs/AI-Web3-School#tab=learning

## 隐私与安全提醒（非常重要）
本仓库默认用于 **公开学习沉淀**。请勿提交以下信息：
- 私钥、助记词、钱包 keystore
- API Key、Token、密码、验证码
- 未公开的个人联系方式
- 内部会议链接、私人数据、他人隐私信息

## 仓库结构说明

```text
.
├── README.md                    # 仓库说明与使用指南
├── profile.md                   # 个人学习画像与目标
├── learning-plan.md             # 学习计划（最小路径/推荐路径/挑战路径）
├── daily/                       # 每日学习记录与打卡草稿
├── tasks/                       # 任务拆解、完成证据、复盘
├── experiments/                 # 实验记录、结果与分析
├── handbook-feedback/           # 对 Handbook 的问题与改进建议
├── hackathon/                   # Hackathon 准备资料
├── submissions/                 # 对外提交材料（可公开部分）
└── templates/
    ├── daily-note.md            # 每日记录模板
    └── task-note.md             # 任务记录模板
```

## 使用建议
1. 每天复制 `templates/daily-note.md` 到 `daily/YYYY-MM-DD.md`。
2. 每个任务或实验完成后，在 `tasks/` 或 `experiments/` 新建记录。
3. 遇到 Handbook 内容问题时，在 `handbook-feedback/` 中按模板反馈。
4. 每周回顾 `learning-plan.md`，更新优先级与下周目标。
